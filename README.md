# BraviaCast v2.2 — Smart TV Friendly Mirror & 4K Caster

## What's New in v2.2
1. **Realtime Settings Sync (No Browser Refresh)**: Changing 720p/1080p, FPS, JPEG sharpness, or Audio in the phone app updates the TV stream live without refreshing the TV browser.
2. **Smart TV D-Pad Remote Friendly (No Pointer Needed)**: Press **OK** to Play/Pause, **Left / Right** to rewind/fast-forward -10s/+10s, or **Down** to navigate buttons with the D-Pad focus ring—plus a live **Phone Remote Control** bar inside the app.
3. **4K Web Video Caster & Local File Cast**: Plays native 4K video with your phone screen OFF and zero bitmap allocation lag.
